# Fleet management

These guides cover what a fleet needs beyond raw tracking: the vehicle record that gives a device its identity, the maintenance schedule attached to it, and the trip categorisation that separates business use from private.

* [Managing vehicles and service works](service-works.md): the vehicle record and the maintenance due against it.
* [Using driver journals](driver-journals.md): categorising trips so transport use can be split between business and private.
* [Using tags](use-tags.md): labelling across entity types so related things can be found together.
