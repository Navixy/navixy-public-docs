# Rules and notifications

A rule watches for a condition, logs an event when it is met, and notifies someone. These guides follow that chain from defining the condition to getting the result into an application.

* [Using rules](use-rules.md): defining the conditions the Navixy platform watches for.
* [Working with notifications](work-with-notifications.md): reading the events a rule logged and how they are delivered.
* [Receiving push notifications in your app](get-push-notifications.md): getting events to an app without polling for them.
