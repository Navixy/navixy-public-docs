# Field service management

Field service work follows a cycle: a task is created and assigned, an employee's status changes as they work it, and information comes back from site as a form or a check-in. These guides walk that cycle with the calls in order.

* [How to create and assign tasks](manage-tasks.md): the starting point, and what the other three build on.
* [Changing employee statuses](change-task-statuses.md): recording what an employee is currently doing.
* [Using task forms](create-forms.md): collecting structured information when a task is completed.
* [Working with check-ins](check-ins.md): recording what an employee reported from a location.
