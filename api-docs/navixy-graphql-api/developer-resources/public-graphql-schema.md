# Public GraphQL schema

The GraphQL schema for Navixy GraphQL API is public and split into several parts:

* Common resources: Types and operations [shared by the entire API](https://app.gitbook.com/s/eaPUYn5ATRhY1fALtOkq/core-api-reference).
* Business Data Repository: Types and operations specific to [Business Data Repository](https://app.gitbook.com/s/eaPUYn5ATRhY1fALtOkq/business-data-repository).
* Tracking: Types and operations specific to [Tracking](https://app.gitbook.com/s/eaPUYn5ATRhY1fALtOkq/tracking).
