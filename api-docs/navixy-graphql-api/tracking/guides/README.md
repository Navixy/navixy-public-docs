# Guides

This section contains step-by-step guides for the basic scenarios of using Tracking, a product served by Navixy GraphQL API. Each guide builds one view that a fleet application needs, from the first query to the stream or the request that keeps it complete.

### Guides in this section

- [Building a live fleet map](building-a-live-fleet-map.md): where every asset is, whether it moves and reports, and what its sensors say, kept current with a state stream
- [Reading a vehicle trip history](reading-a-vehicle-trip-history.md): request a device and period, receive trips and stops with totals, complete a partial result, and load the route of each trip
