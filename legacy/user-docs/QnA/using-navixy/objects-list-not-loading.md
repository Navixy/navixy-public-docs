# Objects list not loading

## Question

Why isn't the objects list loading in the web interface?

## Answer

Clear all filters and the search field on the objects list first. Those settings hide devices without showing an error.

If some devices appear but not all, that is usually a service plan tracker limit, not a failed page load. See [Not all devices are shown in the objects list](not-all-devices-are-shown-in-the-objects-list.md).

If the list stays empty after you clear filters, try another browser or an incognito window. Then ask your service provider to check that the account is active and that the plan allows the expected number of trackers.
