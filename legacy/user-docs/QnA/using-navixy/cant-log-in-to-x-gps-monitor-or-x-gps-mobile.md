# Can't log in to X-GPS Monitor or X-GPS Mobile

## Question

I can't log in to the X-GPS Monitor or X-GPS Mobile app. How do I get access back?

## Answer

Log in with the same username and password as in the web interface. If the app asks for a QR code or a server address, click the QR code button under the web login form and scan the code with the app. **X-GPS Tracker** doesn't use a username and password: it asks for the device ID from your invitation.

If you forgot your password, tap **Forgot password** in the app and enter the email address of your account. Then open the reset link in the email that you receive.

If you still can't log in, check the spam folder for the reset email. Then ask your service provider to check that your user account is active and not blocked.
