# AI Assistant missing from user interface

## Question

How can I turn on AI Assistant again in my users' interface?

## Answer

Navixy AI Assistant appears in the user interface only when the **Display Help** option is on and uses the default Navixy link. To turn on AI Assistant again, follow these steps:

1. In Navixy Admin Panel, go to **Settings** → **Service preferences**.
2. In the **Support** section, select **Display Help**.
3. If the field under **Display Help** contains your own link, click **Restore default link** next to the field.
4. Click **Save**.

When **Display Help** uses your own link, the user interface shows your page as Help and hides AI Assistant. You can't use your own Help link and AI Assistant at the same time.
