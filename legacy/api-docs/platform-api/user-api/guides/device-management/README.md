# Device management

These guides cover the device side of an integration: getting hardware onto the Navixy platform in the first place, changing its configuration once it is there, and extending tracking to objects that cannot carry a tracker themselves.

* [Activate device](activate-device.md): registering a GPS device or a mobile app on the platform.
* [Sending commands to a GPS tracker via IP protocol (OTA)](send-commands.md): reconfiguring a device remotely instead of physically.
* [Tracking stationary objects with BLE tags](ble-beacons.md): using radio tags for objects that have no device of their own.
