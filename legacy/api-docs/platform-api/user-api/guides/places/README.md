# Places

Both guides here give a location a name the rest of the Navixy platform can use: a geofence is an area that a rule can watch, and a place is a point that a task can be assigned against. Reports name both instead of raw coordinates.

* [Managing geofences](manage-geofences.md): creating areas and using them to limit where a rule applies.
* [Managing POIs](manage-pois.md): creating the client sites and depots that tasks are assigned against.
