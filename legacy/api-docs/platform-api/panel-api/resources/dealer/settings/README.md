# Settings

Dealer settings control how the Admin Panel and the Navixy platform present themselves to a dealer's users: branding images, the email and SMS originators used for notifications, and platform-wide service behavior such as default maps and registration options. Each settings group has its own page with the full parameter and response schema, plus a panel for sending a test request. Update operations across these settings replace the stored object in full rather than merging changes, so read the current values before updating them.

* [Branding Customization](image.md): upload and delete the images used to brand the panel and generated documents.
* [Notification Settings](notification.md): configure the email, SMS, and caller ID originators used for outgoing notifications.
* [Service Settings](service.md): configure platform-wide behavior such as default maps, locale, currency, and user registration options.
