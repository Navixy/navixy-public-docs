# Message values in Device Action command text

## Question

Can the command text in a Device Action node include a value from the message?

## Answer

No. The **Command string** field holds fixed text, and the node sends it exactly as written.

See [Device Action](https://app.gitbook.com/s/6RLA9o0EecKpLxHiaeR4/products/iot-logic/nodes/device-action).
