# Webhook responses in IoT Logic flows

## Question

Can an IoT Logic flow use the response to a Webhook request?

## Answer

No. The **Webhook** node sends the request, and the path ends there. Nothing comes back into the flow.

See [Webhook](https://app.gitbook.com/s/6RLA9o0EecKpLxHiaeR4/products/iot-logic/nodes/webhook).
