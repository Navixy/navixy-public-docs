# IoT Logic output to Navixy and your own system

## Question

Can one IoT Logic flow send data to both the Navixy platform and my own system?

## Answer

Yes. Add two **Output Endpoint** nodes, one in each mode, and connect both to the same point in the flow.

See [Output Endpoint](https://app.gitbook.com/s/6RLA9o0EecKpLxHiaeR4/products/iot-logic/nodes/output-endpoint).
