# Several commands in one Device Action node

## Question

Can one Device Action node run several commands?

## Answer

Yes. Use **Add action** to add each command. The node runs them in the order that they are listed.

See [Device Action](https://app.gitbook.com/s/6RLA9o0EecKpLxHiaeR4/products/iot-logic/nodes/device-action).
