# Device commands through Webhook nodes

## Question

Can I send a command to a device through a Webhook node?

## Answer

Only through a receiving system that can command the device itself. To act on the device directly, use a **Device Action** node.

See [Webhook](https://app.gitbook.com/s/6RLA9o0EecKpLxHiaeR4/products/iot-logic/nodes/webhook) and [Device Action](https://app.gitbook.com/s/6RLA9o0EecKpLxHiaeR4/products/iot-logic/nodes/device-action).
