# Guides

This section contains step-by-step guides for the basic scenarios of using Rules and notifications, a product served by Navixy GraphQL API.

### Guides in this section

- [Creating and managing rules](creating-and-managing-rules.md): List the parameters for a rule editor, create a rule, turn it on, change it, find the rules of an asset, and delete it.
- [Reading rule history](reading-rule-history.md): List when a rule activated and deactivated for each asset, and read the values that met its equations. Find out why a rule didn't send a notification.
- [Receiving notifications](receiving-notifications.md): Open the notification stream, handle its refusals and endings, find the notifications that the user missed, and keep an unread count.
