# Guides

This section contains step-by-step guides for the basic scenarios of using IoT Logic, a product served by Navixy GraphQL API.

### Guides in this section

- [Creating and updating flows](creating-and-updating-flows.md): Create a flow for a group of devices, read it back, replace its graph, enable it, and delete it.
- [Reading flows and device data](reading-flows-and-device-data.md): Find the attribute names of your devices, check what a flow calculated, list flows, and find the flows that a device is in.
- [Calculating values in several steps](calculating-values-in-several-steps.md): Build a chain of nodes where each step reads the values of the previous one, and read earlier values from the history of a device.
