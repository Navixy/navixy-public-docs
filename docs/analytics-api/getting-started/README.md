# Getting started

The Analytics API has 2 approaches. Choose the guide for the approach that fits your task:

| Guide | Approach | Choose it when |
| --- | --- | --- |
| [API with session token](api-with-session-token.md) | The API, with the session token of a signed-in browser | You want the full data of a report or the rows of a dashboard panel, for your own requests and scripts that you run while you work |
| [Tools with API key](tools-with-api-key.md) | The tools, with an access token from a Navixy Console API key | You build an integration or an AI agent that runs on its own and reads report summaries and dashboard data |

To learn how each approach authenticates, see [Authentication](../authentication.md).
